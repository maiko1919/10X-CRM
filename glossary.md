# Glossary

## API
A way for applications to communicate and exchange data.

---

## Authentication
The process of verifying a user's identity before granting access.

---

## Authorization
Determines what an authenticated user is allowed to access.

---

## Local Storage
Browser storage used to save data that persists after page refresh.

---

## Session
Information about the currently logged-in user.

---

## Fetch API
A JavaScript interface used to send HTTP requests.

---

## CRUD
Create, Read, Update, Delete — the four basic operations for managing data.

---

## DOM
Document Object Model, the structure that JavaScript uses to interact with HTML elements.

---

## Event Listener
A function that waits for user interactions such as clicks or typing.

---

## Responsive Design
A design approach that allows a website to work correctly on different screen sizes.
