# 10X CRM

## About

10X CRM is a simple Customer Relationship Management (CRM) web application built with Vanilla JavaScript.

The application allows users to register, log in, manage clients, track sales progress, update their profile, and store all data in Local Storage.

This project was developed as the final JavaScript module project.

---

## Features

- User Registration
- User Login
- Authentication Guard
- Session Management
- Dark / Light Theme
- Dashboard
- Client Management
- Add Client
- Delete Client
- Search Clients
- Filter Clients
- Sort Clients
- Change Client Status
- Client Details
- Notes
- Reminder
- Profile Management
- Change Password
- Reset CRM Data
- Toast Notifications
- Local Storage Persistence

---

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript (ES6)
- Local Storage
- Fetch API
- DummyJSON API

---

## How to Run

1. Clone this repository.

2. Open the project in Visual Studio Code.

3. Run the project using Live Server.

4. Register a new account.

5. Start managing your CRM.
